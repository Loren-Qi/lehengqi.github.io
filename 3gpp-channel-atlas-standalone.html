04 / CLAUSE 7.1 & 7.3

传播角度与天线：MIMO 的基础

标准不只要知道信号到达的时间，还要知道它从哪里发出、从哪个方向到达。

参数全称直观意义
AOAAzimuth of Arrival接收端看到的水平到达方向
AODAzimuth of Departure发射端看到的水平离开方向
ZOAZenith of Arrival接收端从 +z 轴量起的到达方向
ZODZenith of Departure发射端从 +z 轴量起的离开方向

为什么要区分 GCS / LCS？

GCS 是系统全局坐标系；LCS 是某个天线阵列自身的局部坐标系。天线朝向变化时，需要将阵元方向图和极化响应转换到统一坐标系。

为什么这些角度影响 MIMO？

不同路径的空间方向，会决定阵列各阵元收到的相位差。角度扩展与阵列布局共同影响相关性、波束指向和空间复用。

阅读公式 (7.5-22) 前先记住

一个 MIMO 信道系数不仅由“多径功率”决定，还包含发射/接收天线方向响应、极化矩阵、阵元位置相位以及多普勒相位。

原文：§7.1、§7.3

为什么还需要 LOS 概率？

06 / CLAUSE 7.5

快衰落模型：从 Cluster 到 Ray

这是整份标准的核心：如何从统计场景一步步生成复数信道系数？

CLUSTER / 簇

多条相近路径组成一个簇

簇在时延、角度等参数上体现局部关联。一个簇不是现实中的一堵固定墙。

RAY / 射线

簇内部的细粒度多径分量

一条射线拥有自己的方向、极化、相位和多普勒属性。

先学会七个大尺度参数（LSP）

参数英文它告诉我们什么
DSDelay Spread多径在时延轴上分散得多宽
ASA / ASDArrival / Departure Azimuth Spread水平到达/出发角分布宽度
ZSA / ZSDArrival / Departure Zenith Spread垂直到达/出发角分布宽度
SFShadow Fading大尺度随机遮挡造成的损耗变化
KRicean K-factorLOS 确定性分量与散射分量的功率比

原文的 12 步生成流程

把整套过程拆成四段，比直接死记原文中的所有符号更容易理解：

01—04

确定环境与大尺度统计

场景/阵列/位置 → LOS 状态 → 路径损耗 → DS、角度扩展、K 和 SF；标准会考虑这些参数之间的相关性。

05—06

生成簇的时延与功率

利用分布生成各簇时延、簇功率，再归一化。通常较晚到达的簇平均功率较弱，但不要求每条严格单调。

07—10

生成角度、极化与初始相位

从 ASA/ASD/ZSA/ZSD 得到到达/出发角，对射线进行耦合，生成 XPR 和随机初相。

11—12

合成复数信道系数

结合天线方向图、阵元几何、多普勒、极化和相位，得到各收发天线单元间的信道，并施加路径损耗与阴影衰落。

RMS Delay Spread 不是“最后一路减第一路”

教学推导：p 是归一化路径功率，∑p = 1

时延扩展越大，宽带 OFDM 子载波之间的信道响应通常越容易出现显著差异。但实际影响还取决于信号带宽、路径功率分布等因素。

07 / EQUATION (7.5-22)

信道系数到底由哪些部分组成？

原式较长，但它的结构并不神秘。

①功率缩放

— 簇功率分配到簇内射线。

②天线方向响应

发射与接收阵元在对应到达/出发方向的响应。

③极化矩阵 / 初始相位

不同极化分量的耦合及相位旋转。

④空间相位

— 阵元位置决定相位。

⑤多普勒项

— 终端运动导致信道随时间变化。

最大多普勒频移的常用近似；实际射线多普勒取决于运动方向与入射角

若终端以 30 km/h 移动，载波为 3.5 GHz，最大多普勒频移约 97.2 Hz。不同射线的多普勒频移不同，合成后就会形成随时间波动的信道。

联系 MIMO 信道矩阵

对每一个时间与频率位置，所有接收阵元和发射阵元之间的复数系数可以组织成 H(f,t) ∈ ℂNr×Nt。MIMO 检测、预编码和信道估计最终都与它有关。

08 / CLAUSE 7.7

TDL vs CDL：仿真应该选哪个？

学术研究中最常见的两个 3GPP 链路级信道模型家族。

01 · TAPPED DELAY LINE

TDL

用一组具有各自时延、平均功率和随机衰落的 Tap 描述信道。标准称其适用于简化链路级评估，例如非 MIMO 评估。

  • 看功率延迟分布（PDP）
  • 研究 OFDM 频率选择性衰落
  • 从 SISO 信道估计开始
02 · CLUSTERED DELAY LINE

CDL

在簇延迟和功率之外，还给出 AOD / AOA / ZOD / ZOA、极化和簇内角度扩展等信息。

  • 研究阵列空间相关性
  • 波束赋形与 Massive MIMO
  • 角度、空间结构相关问题
模型家族非视距（NLOS）视距（LOS）
TDLTDL-A / B / CTDL-D / E
CDLCDL-A / B / CCDL-D / E

09 / CLAUSE 7.6

扩展模型：让信道更接近复杂场景

当基础模型无法覆盖高频、大阵列或动态运动场景时，才继续引入高级组件。

7.6.1

Oxygen absorption · 氧气吸收

在特定高频段额外考虑随频率变化的气体吸收损耗。

7.6.3

Spatial consistency · 空间一致性

终端相邻位置的角度、时延和大尺度参数应平滑相关，而不应每走一步就生成毫无关系的环境。

7.6.4

Blockage · 遮挡

研究人体、车辆或环境物体对传播路径的遮挡影响。

7.6.13

Near-field · 近场信道

在大阵列和短距离条件下，考虑球面波前特性。

7.6.14

Spatial non-stationarity · 空间非平稳

大阵列不同阵元可能观察到不同的传播簇强度与可见性。

学习顺序建议

先做会跑的 TDL/OFDM → 再理解 CDL 的角度项 → 最后根据科研题目决定是否需要近场、遮挡或空间一致性模型。

可直接复制的 Python 入门示例

以 TDL-A 的前四个 Tap 生成一个教学用复高斯快照；这不是完整 TDL 实现。

Python · numpy + matplotlib
import numpy as np
import matplotlib.pyplot as plt

# TR 38.901 TDL-A 的前四个 Tap（教学简化）
delay_norm = np.array([0, 0.3819, 0.4025, 0.5868])
power_db = np.array([-13.4, 0, -2.2, -4.0])
DS = 100e-9                 # 目标时延扩展 100 ns
tau = delay_norm * DS

power = 10 ** (power_db / 10)
power /= power.sum()         # 归一化平均功率
rng = np.random.default_rng(42)
h = np.sqrt(power / 2) * (
    rng.standard_normal(4) + 1j * rng.standard_normal(4)
)

f = np.linspace(-20e6, 20e6, 1000)
H = np.exp(-1j * 2 * np.pi * np.outer(f, tau)) @ h
plt.plot(f / 1e6, 20 * np.log10(np.abs(H) + 1e-12))
plt.xlabel("Frequency offset (MHz)")
plt.ylabel("Channel magnitude (dB)")
plt.grid(True)
plt.show()
